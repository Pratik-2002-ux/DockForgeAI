# XAI explainability

Global native additive importance, descriptor contributions, mapped Morgan environments, local cards, and cross-seed summaries describe model behaviour. They do not establish chemical mechanisms or biological causality. Hashed Morgan bits can collide, so a bit may represent several atom environments. Nearest neighbours explain by analogy only; no molecules are generated or proposed.
# Explanation validation

Parameter, label and feature randomization, feature-removal controls, method agreement, and local-fidelity checks test whether explanations track model behaviour. SHAP and other importance methods do not establish causal chemical or biological mechanisms.
