## [1.0.0] - 2026-08-07

### Added

- AI-assisted prospective compound-screening workflow
- Applicability-domain and uncertainty assessment
- Drug-likeness and PAINS/Brenk alert evaluation
- AutoDock Vina ligand docking
- Protein-ligand interaction profiling
- Evidence-weighted consensus ranking
- Validated 5 ns reference molecular-dynamics simulation
- Three comparative 1 ns molecular-dynamics pilot simulations
- RMSD, hydrogen-bond, contact and distance analyses
- Compact result packages with SHA-256 checksums
- Configuration-driven one-click pipeline runner
- Resume, stage selection, logging and run manifests
- Interactive Streamlit platform
- Candidate explorer with 2D ligand structures
- Comparative MD visualization
- Interactive 3D protein-ligand viewer
- Pipeline execution and repository monitoring interfaces

### Scientific scope

DockForgeAI v1.0 supports computational lead prioritization for a selected
protein target. Current molecular-dynamics trajectories are technical pilot
simulations and do not establish experimental binding, inhibition, toxicity,
safety or biological efficacy.

### Future direction

DockForgeAI v2.0 will introduce project creation, target and ligand uploads,
new-dataset execution, persistent project storage, enhanced molecular
visualization, progress monitoring and automated reporting.
